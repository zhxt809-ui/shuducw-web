# 百度搜索资源平台配置清单（shuducw.com）

> 目的：让百度更快更全地收录官网，并获得收录/异常/移动端诊断数据。
> 说明：以下操作需要**用户本人的百度账号**登录 https://ziyuan.baidu.com 完成，代理无法代登。
> 预计耗时：首次 20-30 分钟；日常巡检每周 5 分钟。

## 一、首次配置（一次性）

### 1. 登录并添加站点

1. 打开 https://ziyuan.baidu.com ，用百度账号登录（建议绑定公司常用手机号）；
2. 进入「用户中心 → 站点管理 → 添加网站」；
3. 填写站点：`https://www.shuducw.com`（**不要填裸域**，我们已统一 301 到 www）；
4. 按提示选择**文件验证**方式：平台会给一个验证文件（如 `baidu_verify_xxxxx.html`）和一段验证码（如 `xxxxx`）。

### 2. 文件验证（需要我配合部署）

1. 把验证文件名和内容发给我（例如文件 `baidu_verify_abc123.html`，内容 `abc123`）；
2. 我会把文件部署到服务器 `public/` 目录（部署后访问 `https://www.shuducw.com/baidu_verify_abc123.html` 返回 200）；
3. 你在百度平台点「完成验证」即可。

### 3. 提交 sitemap

1. 左侧菜单「普通收录 → sitemap」；
2. 提交地址：`https://www.shuducw.com/sitemap.xml`；
3. 提交后百度会定期抓取（sitemap 已配置 ISR 5 分钟自动更新，新增文章/页面会自动进 sitemap）。

### 4. 开启 API 主动推送（推荐，抓取更快）

1. 左侧菜单「普通收录 → 主动推送（API）」；
2. 页面会显示你的专属 **token**（一串字符串）和一个接口地址
   （形如 `http://data.zz.baidu.com/urls?site=www.shuducw.com&token=XXXX`）；
3. 把 token 发给我，我会在内容发布脚本里接入百度 API 推送：
   每次发新文章后自动 POST URL 列表到该接口，百度秒级收录；
4. 也可以临时手动推送：在「普通收录 → 普通收录（手动提交）」粘贴
   `https://www.shuducw.com/sitemap.xml` 或具体文章 URL。

> 注意：IndexNow（Bing/搜狗等）与百度 API 推送是两套独立通道，互不影响。

### 5. 品牌词保护

1. 左侧菜单「站点设置 → 品牌词保护」；
2. 提交品牌词：`西安数度财务咨询`、`西安数度`、`数度财税`；
3. 审核通过后，搜索结果中品牌词展示由官网主导。

### 6. 移动适配确认

1. 左侧「移动适配」工具，提交 `https://www.shuducw.com/sitemap.xml` 或首页 URL；
2. 系统会给出移动端友好度诊断（我们的页面是响应式设计，一般可直接通过）；
3. 若提示「未适配」，在「适配工具」选择「自适应」并提交首页即可。

## 二、日常巡检（每周 5 分钟）

每周登录一次，看四件事：

| 检查项 | 位置 | 正常状态 |
|--------|------|---------|
| 抓取异常 | 「抓取诊断 → 抓取异常」 | 无异常或少量 404（旧链接） |
| 收录数量 | 「索引量」 | 稳定或上升；新页面 1-4 周内收录 |
| 移动端问题 | 「移动适配」 | 无「错误」项 |
| 恶意流量/盗用 | 「安全检测」 | 无异常 |

## 三、验收目标（每月复盘）

- 收录总量持续增长（当前 27 个 URL 全部收录后，新增区县页/直播电商页逐步进入索引）；
- 品牌词"西安数度财务咨询"搜索首屏出现官网；
- 长尾词（西安XX区代理记账等）进入百度前 20 名；
- 表单线索量可追踪（后台 consultations 数据）。

## 四、常见问题

- **验证文件 404？** 检查是否已部署到 public/ 且 URL 大小写一致（文件名区分大小写）。
- **sitemap 提交后无收录？** 新站正常 1-4 周，先确保「抓取诊断」能抓通首页；可手动提交 1-2 个核心页面 URL 加速。
- **API 推送报错？** 确认 token 与 site 参数一致，URL 必须是 `https://www.shuducw.com/...` 开头且可访问。
- **文章改标题后收录旧？** 百度按 URL 识别，标题变化会自动更新；不要改 slug（URL），改 slug 等于新页面。
