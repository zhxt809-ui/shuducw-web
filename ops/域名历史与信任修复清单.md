# 域名历史与信任修复清单（子域名被冒用问题）

> 建立日期：2026-10-06　｜　触发原因：用户反馈"这个域名一直是公司网站，但有几个月出现子域名被冒用问题"
> 为什么重要：搜索引擎的信任是**按域名整体（含所有子域名）**评估的。若子域名曾被挂过垃圾内容
> （赌博/色情/贷款/仿冒），整个 `shuducw.com` 都会被降信——这能直接解释 Bing/百度/头条"能抓不收录"。

## 四、若确认曾被冒用：清理与申诉步骤

### 第一步：DNS 侧清理（一次做完，之后别再动）
- 删除所有遗留的子域名记录，**尤其指向非本公司 IP 的 A/CNAME**
- 确认没有泛解析 `*`
- 改 DNS 面板密码、开启二次验证、开启域名转移锁
- 已失效的子域名**保持不解析（NXDOMAIN）**——搜索引擎会逐步把它们移除

### 第二步：百度侧
- **死链提交**：搜索资源平台 → 资源提交 → 死链提交，把已失效的垃圾子域名 URL 提交（可用 sitemap 形式批量）
- **安全申诉**：若后台有处罚通知，走「违规处罚申诉 / 网站安全申诉」
- **普通收录**：继续每日推内容页（我们的脚本已在做，配额 10 条/天，已推 38/55）

### 第三步：必应侧
- **内容移除申请**：必应站长后台 → 内容移除，提交仍在索引里的垃圾子域名 URL
- **联系支持**：说明域名曾被他人用子域名滥用、现已清理，请求**重新评估**
- 首页与文章页已接入**单条流式 IndexNow**（发布即提交，`src/lib/indexnow.ts`）

### 第四步：Google（顺手做，成本极低）
- Search Console → 移除（Removals）+ 若子域名曾被索引同样提交

## 六、时间预期（说实话）

- 域名历史遗留的信任损伤，**清理后恢复通常要数周到数月**，比"全新域名自然收录"更慢
- 期间不要做任何加剧风险的动作：**不批量推 URL、不改 URL、不买链接**
- 这条线与"外链建设"是**两条并行主线**：外链解决"权威度"，域名清理解决"信任度"，
  两个都做了，Bing/百度才会真正放收录
